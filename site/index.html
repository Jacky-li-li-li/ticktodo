        01
        
以 todo 为中心

        
todo 是索引：这件事做到哪、碰过哪些会话、停在哪里。而不是一条永远往下翻的聊天列表。

      

      

        02
        
始终在手边

        
360×520 的面板常驻菜单栏、置顶在桌面一角。⌘⌥T 随时显示或收起，不会埋在别的窗口下面。

      

      

        03
        
本地优先

        
数据放在本机 ~/.ticktodo，没有账号、没有云端；会话正文始终留在各工具自己的存储里。

      

    

  






  

    

      
能做什么

      
一条线索要用到的，
都在这个面板里。

      

        它不是聊天客户端，而是索引与入口：记录、聚合、接着做，并且让外部 agent 也能往这里写线索。

    怎么做到的
    
      
    适配器只读，
    面板只做索引，
    会话留在工具里。
    
      
    
        Ticktodo 是一个菜单栏应用，为每个工具实现同一个合同；会话元数据每次都向工具现问，不在 Ticktodo 里建镜像表。
      
    
    
    

    
    
      
    
        
    各工具的会话存储
    只读
    
        
      
          
    • ~/.pi/agent/sessions
      • 
          
    • ~/.claude/projects
      • 
          
    • ~/.codex/sessions
      • 
          
    • opencode.db
      • 
          
    • + 另外 11 个，各有各的格式
      • 
        
    
        
    只读 header、首尾 user 消息、cwd 与时间；不复制正文。
    
      
    
      
    
      
    
        
    15 个适配器
    只吐证据
    
        
      
          
    • detect · list · describe
      • 
          
    • resume · launch · verify
      • 
          
    • usage · discoverProjects
      • 
        
    
        
    每个适配器声明自己能做什么（launch / prefill / 只读），不做归并、不缓存别的工具的数据。
    
      
    
      
    
      
    
        
    Ticktodo（菜单栏）
    只做索引
    
        
    TodoStoreProjectIndexSessionServiceLaunchMCP
    
        
    
          线索与绑定存在 ~/.ticktodo，会话按需现问。写入只有一份锁与原子写：面板、pi 扩展、MCP server 三边共用。
        
    
        
    ~/.ticktodo
    
      
    
      
    
      
    
        
    你正在用的地方
    一步到位
    
        
    
          置顶面板（⌘⌥T）
          终端里接着做
          深链接回到 App
          外部 agent 走 MCP
        
    
        
    回到上次的地方 —— 会话始终在它自己的工具里，只有索引是我们的。
    
      
    
    
    

    
    
      
    
        
    数据放在哪
    
        
      
          
    • data/todos.json、settings.json可同步
      • 
          
    • sessions/panel-chat/面板对话正文建议留在本地
      • 
          
    • cache/项目缓存、窗口位置、终端脚本可再生
      • 
          
    • exports/JSON + Markdown 导出只有索引
      • 
        
    
        
    根目录可用 TICK_HOME 覆盖；这里不存任何 API Key。
    
      
    
      
    
        
    几条不越过的线
    
        
      
          
    • 会话元数据以工具为准：不建镜像表、不缓存正文。
      • 
          
    • 「接着做」不会在错误的目录里跑工具：目录失效就明说，不静默换路径。
      • 
          
    • 桌面应用是只读的：索引 + 深链接；定位不到就如实说，不假装成功。
      • 
          
    • 自配 provider 的 Key 经 safeStorage 进系统钥匙串，绝不写进可同步的数据目录。

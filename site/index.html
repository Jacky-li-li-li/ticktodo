它是什么

不用再靠回忆，
挨个工具翻找会话。

01

以 todo 为中心

一个 todo 就是一条线索，它在各个工具里的会话都聚在下面：做到哪，一眼看清，想接着做就点进任意一个会话。

02

始终在手边

常驻菜单栏的悬浮小面板，置顶在桌面一角，不抢窗口，也不会被埋掉。

03

本地优先

数据存放在本机 ~/.ticktodo，不需要账号，也不依赖云端。

能做什么

刚好够用的几个功能。

置顶悬浮面板

360×520 的小窗口，可以一直置顶，也可以设成失焦自动隐藏。

Todo 增删改查

完成只是改个状态，不会删掉，做过的工作都还在，随时能回头找。

绑定 AI 会话

每条 Todo 都可以绑定一个 AI 会话（pi、WorkBuddy 等），线索和上下文不再走散。

一键投递到 pi

选好工作目录 cwd，一键把 Todo 内容通过剪贴板或启动参数送进 pi 会话。

agent 自己记 Todo

装上 Ticktodo 扩展后，agent 可以直接调用 create_todo，把待办写回 Ticktodo。

会话互不打扰

面板里的对话和 CLI 里的会话相互隔离，各聊各的，不串线。

怎么用

三步，开始用线索管理会话。

安装并常驻托盘

下载 macOS 版或用终端命令安装。Ticktodo 会待在菜单栏，点一下就弹出面板。

记下一条线索

在面板里写下 Todo，或者让装了 Ticktodo 扩展的 agent 直接替你 create_todo。

投递并绑定会话

为这条 Todo 选好 cwd，一键投递到 pi。会话绑定在线索上，下次从这里接着来。

# Tick 设计规范（UI-SPEC）

> 来源：Ardot 设计稿 `737202736253140` → 「第二轮 · Calm Panel 线索式」页面（含第二轮 B / 第二轮 C）。
> 本文把所有视觉数值、材质配方、组件结构与交互规则整理成可直接实现的规范。
> 冲突时以本文为准；本文未覆盖的以画布为准。**第一轮（玻璃拟态 + 传统列表）仅作历史对照，不参与实现。**

---

## 0. 一句话定位

Tick 是「AI 会话的索引层」：**线索（thread）是索引，agent 会话是被索引对象**。
所以界面上不出现「清单/打卡/计数」，只有一个动作——**接着做**。

---

## 1. 设计原则（落到实现上的四条硬约束）

| 原则 | 具体约束 |
|---|---|
| **无压力** | 不计待办数、不显示 overdue、不打勾庆祝、不用红字催。归档是「收好」，不是「打卡」 |
| **常驻可见** | 面板默认贴屏幕右上角常驻（360×520），**不自动收起、不自动降级**；「不影响观看」靠材质与对比，不靠躲起来 |
| **不夺焦** | 唤起不改变前台 app 激活状态；捕获态需要焦点时，收起后必须把焦点与光标还给原窗口 |
| **可控 > 智能** | 穿透开关、尺寸、位置都由用户决定；系统不猜「你最近用哪个项目/工具」 |

置顶面板的补充口径：**穿透开关**（`setIgnoreMouseEvents(true,{forward:true})`）——穿透态必须有显式「穿透中」标记，且退出必须键盘可达；**透明度只作用在底色层，文字保持 ≥70%**。

## 2. 基础令牌

### 2.1 色板

| 名称 | 值 | 用途 |
|---|---|---|
| Accent | `#0A84FF` | 主按钮、当前会话、光标、选中态 |
| Accent Text | `#9EC5FF` | 强调文字、可点文字、勾选描边 |
| Success | `#34C759` | 已完成勾选、投递成功 toast |
| Danger | `#FF6B6B` | 删除、破坏性动作 |
| Panel Base | `rgb(18,20,31)` ≈ `0.07,0.08,0.12` @45% | 玻璃面板底色 |
| Board BG | `#0C0D12` | 画布底板（仅展示用） |

**文字层级一律用白色透明度表达**（不使用独立灰色）：

| 层级 | 白透明度 | 用途 |
|---|---|---|
| 主标题 | 100% / 92% | 卡片标题、页面标题 |
| 行标题 | 85% | 线索行标题 |
| 正文 | 75% / 70% | 提示正文、消息内容 |
| 次要 | 58% / 55% | 上次停在哪一句、空态说明 |
| 辅助 | 50% / 45% | 面板顶栏标题、标签、元信息 |
| 弱 | 38% / 35% | 时间、底部说明 |
| 极弱 | 32% | 归档态时间 |

### 2.2 字体

- 唯一字族 **Inter**（中文回退系统 PingFang SC）
- 字重只用四种：Regular 400 / Medium 500 / SemiBold 600 / Bold 700

| 角色 | 字号 / 字重 |
|---|---|
| 卡片标题 / 页面标题 | 15 / SemiBold |
| 提示卡标题 / 页面顶栏标题 | 13 / SemiBold |
| 面板顶栏标题 | 12 / SemiBold |
| 线索行标题 | 12 / Medium |
| 主按钮文字 | 12 / SemiBold |
| 胶囊按钮文字 | 11 / SemiBold |
| 副文案、上次一句 | 11 / Regular |
| 标签、时间、元信息 | 10 / Medium 或 Regular |
| 注释 | 9–9.5 / Regular |

行高：正文 `1.45–1.5`；时间与标签 `1.4`。

## 3. 材质配方（玻璃）

统一公式：**半透明渐变 + 背景模糊 + 1px 内高光 + 细描边 + 轻投影**。不使用实色块。

### 3.1 面板（360×520）

```
fills:   GRADIENT_LINEAR  (上→下)
         白 12% → 白 3%（30%）→ 白 0%（62%）
       + SOLID rgb(18,20,31) @45%
stroke:  白 10%，1px
effects: BACKGROUND_BLUR 40
         INNER_SHADOW 白 18% / y1 / r2
         DROP_SHADOW   rgb(3,5,13) 55% / y30 / r80
```

### 3.2 捕获行（组件 `CaptureLine`）

```
高 46 / 圆角 16 / padding 14 / gap 9
fills:   GRADIENT_LINEAR 白 13% → 白 5%
stroke:  白 14%
effects: BACKGROUND_BLUR 20 + INNER_SHADOW 白 20% (y1/r2)
图标:    ＋（13×13，白 38%）
文字:    「想到什么，先丢下」13 / Regular / 白 45%
```

### 3.3 卡片（线索卡片 / 首次动作卡）

```
圆角 16 / padding 14 / gap 9
fills:   GRADIENT_LINEAR 白 10% → 白 3%  +  Accent 8%（焦点卡）
stroke:  白 8%
effects: BACKGROUND_BLUR 32
```

### 3.4 胶囊按钮（两种，只差颜色与光晕，其余完全一致）

| | 主（接着做 / 继续） | 次（新建会话 / 查看列表 / 恢复） |
|---|---|---|
| fills | Accent 62% → 30% | 白 18% → 6% |
| stroke | 白 30% | 白 20% |
| effects | blur 24 + inner 白 38%（y1/r2） + drop Accent 30%（y6/r18） | blur 24 + inner 白 22%（y1/r2） + drop 黑 28%（y6/r18） |
| 文字 | 11 SemiBold 白 100% | 11 SemiBold 白 100% |

Hover / 高亮态（当前按下的那个）：Accent 34% → 16% + 亮边 `#9EC5FF` 50%，用于「查看列表」「新建会话」被点击时。

### 3.5 Toast（覆盖捕获行，3 秒）

```
位置:  x=14, y=43, 332×46, 圆角 16   ← 正好压住顶部捕获行
fills: SOLID rgb(15,23,31) @92% + 语义色 16%
stroke: 语义色 34%
effects: BACKGROUND_BLUR 24 + DROP_SHADOW 黑 40%（y10/r26）
结构: 13px 图标 + 文字 11 Medium 白 92% + 右侧可选动作（Accent 11 SemiBold）
```

### 3.6 浮层 / 弹层（会话列表、菜单、提示卡）

```
圆角 14–16 / padding 6–14
fills:   SOLID rgb(20,23,33) @96–97%
stroke:  白 14%
effects: BACKGROUND_BLUR 24–32 + DROP_SHADOW 黑 50%（y16/r36）
```

## 4. 组件规范

### 4.1 捕获行 `CaptureLine`（**已组件化，母版 `3:1834`**）

- **必须在每一屏出现**，位置固定为**顶栏正下方第一个元素**（面板第 2 个子节点）
- 例外：**新建会话页不带**（已进入开会话流程，语义冲突）
- 交互：点击 → 展开为输入态（`C2`）；回车收下；Esc 取消

### 4.2 线索行 `ThreadRow`（核心组件）

```
[勾选框 17]  [标题 12 Medium 白85%]  ......  [最右侧槽]
```

| 状态 | 最右侧 | 说明 |
|---|---|---|
| 静止 | **时间**（10 Regular 白 35%） | 首页/菜单显示 `昨天 22:14`；归档页显示完成时间 `今天` |
| 悬停 | **「继续」胶囊**（主按钮） | 时间让位给动作，不并存 |
| 悬停（归档页） | **「恢复」胶囊**（次按钮） | 归档态的唯一动作是撤销 |
| 无会话 | **留空** | 没有可显示的时间，不编造 |

其它规则：行内**没有副标题**；`counterAxisAlignItems: CENTER`（勾选框压在标题中线上）；行高固定 44；**行本身不加底色**（calm 原则），hover 时才出现 10% 白底 + 圆角 12。

### 4.3 勾选框 `CheckBox`

| 状态 | 样式 |
|---|---|
| 未完成 | 17×17 圆形，1.5px 描边 白 30%，无填充 |
| 已完成 | 17×17 圆角方块（radius 9），**Success 实心** + 居中 9×9 **白勾** |

点击未完成 → **立即归档**（无确认框）→ 顶部 toast 3 秒「已归档「X」· 撤销」。
已完成态的标题同时**变淡到 45% + 加删除线**。

### 4.4 顶栏

```
[标题 12 SemiBold 白50%]  ......  [⋯ 14×14 白 32%]
```

- 首页标题「线索」，归档页「归档」，认领页「认领历史会话」
- 页面级（新建会话）改为：`[← 14×14] [标题 13 SemiBold 白 90%]`，不放 `⋯`

### 4.5 会话浮层（查看列表）

- 位置：**触发按钮正下方**，右对齐面板内容区
- 结构：标签「这条线上的对话」→ 会话行（实心点 = CLI 会话 / **空心点 = 面板 Chat，与 CLI 分开存**）→ footer「＋ 新建会话 · 认领历史会话」
- 每行两行文字：第一行时间 + 状态（当前加 Accent 底），第二行「上次停在哪句话」
- 点条目 = `pi --session` 切回；浮层内**不显示用量徽标**，用量作 9px 灰字放在行内

### 4.6 提示卡（工具检测）

只在**点「新建会话」且本机无可用 agent 工具**时出现，紧贴触发按钮下方：

```
图标(中性蓝,非红) + 标题 13 SemiBold「没有可用的 agent 工具」
+ 说明 10.5「Tick 只做索引、不内置模型…记线索不受影响」
+ 检测结果 9.5「已扫描本机：pi · claude code · codex —— 均未检测到会话目录」
+ 动作「重新检测」（Accent）
```

**禁止**：常驻横幅、安装引导、红框告警。

## 5. 页面结构（固定顺序）

```
面板 padding 14 / gap 12
├── 顶栏（标题 + ⋯）            ← 固定
├── 捕获行（组件实例）            ← 固定（新建会话页除外）
└── 内容区                      ← 唯一可滚动
    ├── 首页：线索行 × N
    ├── 展开态：线索卡片 + 次要线索
    └── 其它：空态 / 提示卡 / 列表
```

## 6. 交互规范

### 6.1 首页（默认）

- 一开就是**线索列表**，一屏 5 条左右
- 点空白处 → 折叠（回到列表态）
- 点行 → 展开该线索（resume-first）

### 6.2 展开态（按会话数分三态）

| 会话数 | 动作 |
|---|---|
| **0** | 只有「新建会话」 |
| **1** | 「接着做」+「新建会话」 |
| **N** | 「接着做」+「查看列表」（右上角数字角标 = 会话数） |

- 卡片内容：**先给「上次停在哪」的 user 消息树**，再给动作
- 主按钮文案带工具/项目语境（`在 tick 中打开 pi`），**项目可免选但不能隐式**
- 点「接着做」：有会话 → `pi --session <id>`；无会话 → 用线索的项目新开

### 6.3 归档

- 点勾选 → **立即归档**，无确认框
- 顶部 toast（覆盖捕获行）3 秒：「已归档「X」· 撤销」
- 归档页与首页同构；归档项 hover → 「恢复」
- **会话绑定不清空**，归档只改状态

### 6.4 新建会话（整页，非弹层）

```
← 新建会话
线索名
发送给 AI 的内容（可直接改）  ← 可编辑输入框
用哪个工具（本机检测到 N 个）  ← 胶囊由用户自己选
项目 · tick（已推导）        改
[复制文案并打开 pi]           ← 底部主按钮，Spacer 压到底
文案先进剪贴板，你确认后再发 —— 不自动发送
```

- **文案可编辑**，不是只读预览
- **工具不猜**：不做「默认最近使用」，每次由用户选
- 投递方式默认**剪贴板**（设置可切自动发送）

### 6.5 工具检测

- 只做检测，不做安装引导
- 结果只在**需要它的动作**上暴露（点新建会话）
- 检测不到时：线索照常记，只是不能开会话

### 6.6 认领历史会话（S5）

- 按当前线索的项目**预筛**，最近使用降序
- **一次点一条**，不做批量导入
- 每条一个「认领」；认领后成为该线索的会话

## 7. 文案规范

| 词 | 用法 |
|---|---|
| **线索** | 索引单位（替代「待办/Todo」的界面措辞；数据层可仍叫 todo） |
| **接着做** | 主动作（不用「开始」「打开」） |
| **继续** | 行内悬停动作（比「接着做」更短，同一语义） |
| **查看列表** | 多会话时的会话切换入口 |
| **归档 / 恢复** | 不用「完成 / 删除」（删除是另一件事） |
| **新建会话** | 不用「新对话 / 开新聊天」 |

语气：陈述事实、不催促、不庆祝。空态写「想到什么就丢进来 —— 一行字就够」，不写「快去添加待办」。

## 9. 实现注意（易踩坑）

1. **穿透态**：`forward:true` 才收得到 mousemove，否则悬停加深失效；穿透态点不到面板，**退出必须键盘可达**；不做「N 秒自动退出穿透」。
2. **toast 只能浮在捕获行上**（3 秒），**不要用流内插入**（会把内容顶下去），也不要放面板底部。
3. **浮层类草图必须同时画出触发它的按钮（且是高亮态）**，否则读者无法还原因果。
4. **纹理与模糊消耗**：面板级 blur 40、卡片 32、捕获行 20、按钮 24，不要叠加过多层模糊（GPU 开销）。
5. **项目不可隐式**：按钮/卡片上必须能看到项目名（cwd 传错会让 AI 在错误目录干活）。

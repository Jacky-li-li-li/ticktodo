## 第三轮：置顶「存在感」设计（用户追问：置顶又不希望影响使用）

- 用户追问：置顶面板怎么设计才不影响用户使用。结论写成三原则 + 一条阶梯，画布右侧新增 4 屏（x≈2020 起，与第二轮并列）：
  - **D1 屏上默认态**：模拟真实桌面（mock 编辑器 + 活动窗口边界虚线框），面板贴右边缘成「一条」340×92，距边 16px，
    记住的是**相对边缘的位置**（换分辨率/换显示器仍合理）；活动窗口矩形之外才允许存在。
  - **D2 键盘唤起**：Option+空格 浮出输入层（560×150），**背景不压暗、窗口不变灰**——因为没夺焦；"回车收下 · Esc 就走 · 原窗口不动、光标不丢"。
  - **D3 存在感阶梯**：1 隐（全屏/演示/录屏自动进入，只留菜单栏图标）/ 2 丝（贴边一道细线，鼠标靠近才变宽）/
    **3 一条 ← 默认**（常驻形态）/ 4 面板（临时，用完自动回落）。升降只由「多久没用」+「前台是否全屏」触发，可钉死某一级。
  - **D4 退场时间轴**：0s 唤起 → 回车后收起（焦点归还）→ 8 秒无操作回落为「一条」→ 前台切走 2 分钟再降一级；
    **永不自动跳回更重的形态**，只有用户主动按快捷键才回来（回到上次停留的那一级）。
- 三条硬原则（已写进画布文本）：**不夺焦 / 不遮挡 / 不抢注意力**（无红点、无数字跳动、无循环动画、无自动滚动；
  次级文字 ≤45% 白；蓝只出现在一个点位）。
- **技术风险（需 M2 验证，重要）**：macOS 上"不夺焦显示"用 `showInactive()` / NSPanel nonactivating 可行，
  但**非激活窗口无法接受键盘输入** —— 所以捕获态必须临时激活；方案是「浮层临时激活 → 收起时把焦点还给原 app」
  （需要 NSWorkspace/AppleScript 侧记录并恢复前台 app）。这条决定 D2 是否真能"光标不丢"，进 M2 技术验证清单。
- 待用户拍板：默认级取「一条」还是更轻的「丝」；8s / 2min 两个阈值；是否允许钉死某一级；
  以及"工作期间展开后不自动收起"是否更贴合他的习惯。

## 重要澄清（用户纠正）：要的是「常驻可见」，不是「自动躲起来」

- 用户原话：**面板要常驻屏幕最顶层（例如右上角），不影响整体界面的观看效果，但又能随时看到面板**。
  → 我第三轮做的「存在感阶梯 / 自动退场」方向**被修正**：常驻 ≠ 收起，不能靠隐藏来实现"不影响"。
- 第四轮定案 = **常驻形态设计**，三个杠杆（不是"躲"）：**材质对齐系统 / 避让窗口内容 / 压低对比**。
- 具体数字（写进画布）：
  - **形态**：常驻 360×300（不是 520 高的大面板）——1 条焦点线索 + 2 条线索 + 1 个动作，"一眼读完，不用点开"；
    要看更多才展开成大面板。
  - **位置**：贴右上角，距屏幕右边缘 16px，顶部避开菜单栏再 +16px；**记住相对位置**；可拖到其它角/另一块屏。
  - **材质**：底色 **14%** + 模糊 **56** + 1px 亮边 + 只投 8px/24 的轻阴影（**不把面板从桌面"抬起来"**）；
    **跟随系统浅/深外观**（浅色壁纸 → 亮玻璃 + 深字）。
  - **量化口径**：面板与壁纸亮度差 **≤10%**；边界看得见，但不是画面里最重的那块颜色。
  - **与窗口重叠**：不改任何窗口尺寸；面板降到 **62%**，鼠标移开再淡到 **35%**；

## 用户提案评审 + 第五轮（穿透开关 + 悬停加深）

- 用户提案：① 一个开关让面板**点击穿透**（点不到面板 = 不影响当前操作），可开可关；
  ② **鼠标悬停时颜色加深**看清内容，**移开变 2/3 透明**但内容仍可读。
- 我的评审结论：**方向采纳**（"可控 > 智能"，穿透开关比第三轮的自动避让可靠得多，实现也便宜），**但三处必须修**：
  1. **两态开关 = 模式错误风险**：穿透开着时点面板没反应会被当成"坏了"；
     → 状态必须**显式可见**（面板右上角常驻「穿透中」小签 + 悬停时 1px 亮边，标记不参与点击判定）；
     → **退出必须键盘可达**（全局快捷键 + 托盘/菜单栏同一开关）——否则鼠标用户被锁死。
  2. **穿透 + 悬停加深会连出误击**：加深会让面板看起来"能点"，但穿透时点击照样穿过去。
     → **深浅只表示"鼠标在哪"，绝不表示"能不能点"**。
  3. **"2/3 透明还能看清"要打折**：整块（含文字）降到 33% 在照片壁纸/浅色窗口上读不清。
     → **透明度只能作用在底色层**：底色 14% → 悬停 19% / 静止穿透 8%，**文字保持 ≥70% 不透明度**。
- **新增一个我自己发现的洞（重要）**：穿透态下**连拖动面板都点不到** → 需要"移动模式"入口
  （快捷键或托盘菜单里的"移动面板"），否则用户改不了位置。
- 第五轮画布产出（右侧 y≈6060–7670）：
  **F1 状态矩阵**（A 穿透关+悬停 19% / B 穿透开+悬停 19%+「穿透中」标记 / C 穿透开+静止 底色 8% 文字可读 /
  D 穿透关+静止 默认 14% / **E 反例：整块 33% 文字发灰读不清**）；
  **F2 配套规则 5 条**：退出键盘可达 / 状态显式 / 状态记忆（默认「可操作」）/ 捕获浮层永远可交互（唤起时穿透临时关闭）/
  **禁止项：不做"N 秒后自动退出穿透"**（会让下一次点击在你不知情时被吃掉，比忘记关更糟）。

  穿透切换用 globalShortcut + 托盘；拖动需另设"移动模式"。
